## 评分要求逐项对应

- Team Intro：团队页有学院/本科生身份、姓名学号、三人执行分工和贡献声明。
- Project Proposal：提案页有背景、问题、目标用户、意义及手机设想，无已接入医院系统的宣称。
- Data Collection Plan：研究父页及访谈/问卷子页直接呈现设计、目标对象、主题/结构、原提纲与原题。
- 访谈：4份全量原文；每份9次即时追问，紧接相应回答。
- 问卷：15份满足不少于10份要求；完整原始表格与CSV，22题逐项一致。
- 提交文件：PDF、完整访谈Markdown、CSV、HTML和格式核对清单已生成；真实公网URL及缺失的逐节署名明确待补。
